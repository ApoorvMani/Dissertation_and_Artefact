Why this experiment exists

The earlier WikiText and Jigsaw clean controls mostly measure ordinary English prose. This experiment instead asks whether a defence that works against tokenization attacks accidentally harms legitimate inputs containing code, URLs, emoji, typos, non-English scripts or multiple scripts.

What “utility” means here

For every input we first obtain the victim's ordinary canonical prediction. We then apply each defence to the same exact input.

The main metric is:

not blocked AND classifier decision unchanged

The victim is an English toxicity classifier. Therefore its prediction on Chinese, Arabic, code, URLs, etc. is not treated as semantic ground truth. For these categories we measure defence-induced stability, not classification accuracy.

Dataset provenance

  • Code: 100 real Python functions from CodeSearchNet.
  • URLs: 100 real GitHub source URLs from CodeSearchNet metadata.
  • Emoji: 100 GoEmotions Reddit comments containing emoji; neutral examples are preferred.
  • Misspellings: 100 constructed one-typo versions of Jigsaw benign comments.
  • Non-English: 100 FLORES sentences across Hindi, Arabic, Russian, Chinese and Bengali.
  • Mixed-script: 100 constructed but legitimate bilingual FLORES pairs: English plus an aligned translation.

How to interpret the metrics

Trigger: the defence explicitly marked or transformed the legitimate input.

Block: the legitimate input would be rejected by the deployment policy.

Representation changed: the token IDs reaching the victim differ from ordinary canonical WordPiece encoding.

Decision preserved: the defence did not block the input and did not change the victim's original classification.

Label flip: among inputs that still reached the classifier, the defence changed the classifier's binary decision.

Literature rationale

  • Unicode UTS #39: distinguishes mixed-script and confusable text and provides mixed-script/confusable detection mechanisms.
  • Bad Characters: demonstrates the security relevance of invisible characters, homoglyphs and Unicode reordering, motivating sanitisation.
  • Broken-Token: reports that CPT behaviour changes for multilingual inputs, particularly Chinese and Arabic, making multilingual clean testing important.
  • CodeSearchNet: provides real open-source program text rather than synthetic code.
  • GoEmotions: provides naturally occurring Reddit language from which emoji-containing legitimate inputs are sampled.
  • FLORES: provides professionally translated aligned multilingual text.

Scope

This is a structured utility stress test rather than a population estimate of all possible user input. The misspelling and mixed-script categories are constructed by design and are explicitly labelled as such in the exported dataset.
